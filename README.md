# 검은 장미는 피를 사랑한다 — 웹소설 사이트

리디북스 느낌의 회차 목록 + 뷰어 페이지를 가진 정적 웹소설 사이트입니다.
프레임워크 없이 순수 HTML/CSS/JS로만 만들어져 있어 GitHub Pages에 바로 올릴 수 있습니다.

## 구성
- `index.html` — 표지(히어로) + 전체 회차 목록 + 페이지네이션(1~10페이지, 10페이지에 IF 외전 노출)
- `ep1.html`, `ep2.html`, `ep3.html` — 무료 공개 회차(1~3화) 본문
- `style.css` — 전체 공통 스타일 (블랙 & 레드 테마)
- 4화부터는 `index.html`의 회차 목록에서 잠금 아이콘으로 표시되고 클릭이 막혀 있습니다.
  (본문 페이지가 없어서가 아니라, 유료 전환을 보여주기 위해 의도적으로 링크를 걸지 않았습니다.
  이후 회차를 추가하려면 `ep4.html`처럼 새 파일을 만들고 `index.html`의 `links` 객체에
  `4:"ep4.html"` 형태로 추가하면 자동으로 잠금이 풀리며 목록에 링크가 생깁니다.)

## GitHub Pages로 배포하는 방법
1. GitHub에서 새 저장소를 만듭니다. (예: `black-rose-novel`)
2. 이 폴더 안의 파일들(`index.html`, `style.css`, `ep1.html`, `ep2.html`, `ep3.html`)을
   저장소 루트에 그대로 업로드하고 커밋합니다.
3. 저장소 **Settings → Pages** 로 이동합니다.
4. **Source**를 `Deploy from a branch`로 설정하고, 브랜치는 `main`(또는 `master`), 폴더는 `/root`를 선택합니다.
5. 저장하면 몇 분 안에 `https://아이디.github.io/저장소이름/` 주소로 사이트가 열립니다.

## 새 회차 추가하는 법
1. `ep3.html`을 복사해 `ep4.html`처럼 이름을 바꿉니다.
2. 제목, 본문, 이전/다음화 링크(`.viewer-nav`)를 새 내용으로 바꿉니다.
3. `index.html`의 `<script>` 안 `links` 객체에 `4:"ep4.html"`을 추가합니다.
   → 목록의 4화 잠금이 자동으로 풀리고 클릭 가능한 링크로 바뀝니다.
4. `mainTitles` 배열의 해당 회차에 부제(짧은 소개 문구)를 넣고 싶다면
   세 번째 칸(현재 빈 문자열 `""`)에 문구를 채우면 됩니다.

## 커스터마이징 포인트
- 색상은 `style.css` 최상단 `:root` 변수(`--red`, `--black` 등)에서 한 번에 바꿀 수 있습니다.
- 페이지당 회차 수는 `index.html`의 `PER_PAGE` 값을, 전체 페이지 수는 `TOTAL_PAGES` 값을 수정하세요.
- IF 외전 목록은 `ifTitles` 배열에서 자유롭게 추가·삭제할 수 있습니다(마지막 페이지에만 노출).
